# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report privately through GitHub's
"Report a vulnerability" button on the Security tab of this repository, or email the maintainers.

Include what you found, how to reproduce it, and the impact you expect. We aim to acknowledge reports
within 3 business days and to share a fix timeline within 10.

## Supported versions

Only the latest release receives security fixes unless stated otherwise here.
